This is a Nish groceries order management app which has the following functionalitites:
1. Authentication and authorization using JWT
2. Dashboard to view statistics
3. Products to view product table. and can add products
4. Categories to view the categories and can add categories
5. Orders to view orders and can add orders
6. Users to view users and can add users
7. Coupons to view coupons and can add coupons
